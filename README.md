# Milo — Meet People Who Like What You Like 🤝❤️

Milo is a modern, privacy-first social platform for adults (18+) to connect over shared hobbies and interests, whether looking for new friends or dating.

🌐 **Live Website:** [https://milosathi.netlify.app](https://milosathi.netlify.app)  
👤 **Founder & Developer:** Shiva Tiwari, Ayodhya, India

---

## ✨ Key Features
- **Hobby & Vibe Matching:** Connect based on shared interests (Cricket, Travel, Coding, Music, Chai, etc.).
- **Two Distinct Modes:** Separate 'Friends' and 'Dating' modes.
- **Privacy by Design:** Email, phone, and date of birth are private and never shown to other users.
- **1-Click Google Sign-In:** Seamless and secure authentication via Google OAuth.
- **Realtime Chat:** Instant messaging with built-in block and report safety features.
- **Bot Companions:** Safe chat practice with AI bots (Aarav & Anaya).

---

## 🛠️ Tech Stack
- **Frontend:** Pure HTML5, CSS3 (Glassmorphism), Vanilla JavaScript
- **Backend & Auth:** Supabase (PostgreSQL, Realtime, Row Level Security)
- **Hosting:** Netlify
- **Email Service:** Brevo SMTP

---

## 🔒 Security
- Strict Content Security Policy (CSP)
- HTTP Strict Transport Security (HSTS)
- Anti-clickjacking & XSS protections
- Server-side 18+ verification
